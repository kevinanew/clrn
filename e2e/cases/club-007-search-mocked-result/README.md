# CLUB-007：俱乐部搜索命中固定结果

## 目的与前置条件

使用已有的只读测试账号，在桌面和手机浏览器中验证搜索命中后的完整界面流程。mitmproxy 仅替换本例的俱乐部搜索与资料读取结果，不创建俱乐部，也不申请加入。

## 步骤与预期

| 操作 | 预期 |
| --- | --- |
| 从俱乐部更多菜单打开搜索页 | 搜索输入框可见 |
| 输入 `VisualClubSearch` 并提交 | `GET /v10/club/search` 返回固定俱乐部编号；随后 `PUT /v10/clubs` 读取该编号的资料 |
| 检查搜索结果 | 仅显示名称为“搜索测试俱乐部”的卡片；代理记录两类请求各一次 |
| 保存结果画面 | 关闭可能遮挡卡片的安装提示后，测试报告附带本次实际渲染的截图，供人工审查 |

## 定位契约

使用 `club-tab`、`show-more-button`、`popup-content-container`、`search-club-button`、`club-search-input`、`club-search-item-touchable` 和 `club-search-item-name`。请求仅匹配指定关键字和俱乐部编号，其余登录及业务流量透传。

## 关联问题

已有 CLUB-003 验证真实搜索的空结果；俱乐部初始页视觉场景不输入关键字。本例补充固定命中结果，并由 `visual/cases/club/` 中的独立搜索命中场景执行截图比对。原有空态基准保留，新基准须由 Linux 参考图任务实际采集并审查后提交。
